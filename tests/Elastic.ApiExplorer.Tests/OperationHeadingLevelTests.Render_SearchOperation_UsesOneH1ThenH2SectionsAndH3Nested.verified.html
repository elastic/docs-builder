Run a search

Base URL
https://fixture.example.com Fixture server
  • POST /{index}/_search
Auth

Returns hits that match the query defined in the request. Supports pagination through `size` and `from`.

Read the reference documentation

Required authorization

Requires the `read` index privilege for the target data stream or index.

Requires the `monitor` cluster privilege when profiling is enabled.

Authentication 

Authorization: <value>

Send the encoded key with the ApiKey prefix.

Authorization: Basic <credentials>
Authorization: Bearer <token>

Path parameters

index string required

A comma-separated list of index names to search.

Query parameters

expand_wildcards enum

The type of index that wildcard patterns can match.

Values: all open closed hidden
q string · min length: 1 · max length: 2048

A query in the Lucene query string syntax.

routing string

A custom value used to route operations to a specific shard.

timeout integer | string

The period to wait for a response, as an integer number of milliseconds or a duration string.

pretty boolean deprecated

Pretty-print the response body.

Request body

The search definition using the fixture Query DSL.

query {} Query required

A container for a single query variant. Query containers can nest other query containers, which exercises recursion detection.

fields union string | string[]

A field or list of fields to return, exercising the X | X[] simple-union path.

aggs map string to {} Aggregation

Aggregations to run, keyed by name.

settings map string to string

Free-form string settings, exercising the plain dictionary path.

sort union oneOf

How to sort matching documents.

One of:

Sort by a field value.

field string required

A field name or field path.

order enum
Values: asc desc

Sort by relevance score.

order enum
Values: asc desc
mode enum

Trade accuracy for speed.

Values: fast accurate
pit object

A point in time to search, exercising inline nested object expansion.

id string required
keep_alive string
legacy_size integer deprecated

Use `size` on the query string instead.

Aggregation results keyed by name.
