# Onboard unified releases

Use this path when your product publishes as part of a coordinated Elastic release. Complete the [shared onboarding steps](onboard.md) first.

:::{important}
Unified release onboarding is not self-service yet. Do not add release-time workflows or bundle configuration until this onboarding path is available.
:::

The unified process will coordinate bundle creation across participating repositories. It will also define when teams review bundles before the release. Do not copy the ad hoc GitHub release workflow for this path.
