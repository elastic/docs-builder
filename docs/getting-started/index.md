# Getting started

Welcome to {{dbuild}}! This guide helps you find the right starting point based on what you want to accomplish.

## What do you want to do?

:::{page-card} [Build documentation for a public site](../documentation/assembler.md)
Use assembler builds to compose a unified documentation website with global navigation across multiple repositories.
:::

:::{page-card} [Set up a knowledge base](../documentation/codex.md)
Use codex builds to create a knowledge base environment where multiple repositories publish independently.
:::

:::{page-card} [Preview docs locally](../documentation/isolated.md)
Run an isolated build to preview a single repository's documentation during development.
:::

:::{page-card} [Generate API reference docs](../data/openapi/api-explorer.md)
Generate API reference documentation from OpenAPI specifications.
:::

:::{page-card} [Generate CLI reference docs](../data/cli-schema/index.md)
Generate CLI reference documentation from a CLI schema file.
:::

:::{page-card} [Set up release notes](../data/release-notes/index.md)
Configure changelog-based release notes for your project.
:::

:::{page-card} [Install docs-builder](./installation.md)
Install {{dbuild}} on your local machine.
:::
