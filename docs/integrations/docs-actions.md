# GitHub Actions & workflows

[`elastic/docs-actions`](https://github.com/elastic/docs-actions) is the home for reusable GitHub Actions and shared workflows that integrate {{dbuild}} into your repository's CI/CD pipeline.

These actions and workflows handle publishing, validation, style enforcement, and process enforcement for documentation across Elastic repositories.

See the [docs-actions repository](https://github.com/elastic/docs-actions) for available actions, usage examples, and configuration options.
